# Dorf der Baumeister

Ein Aufbauspiel für Kinder von 8 bis 10 Jahren, das im Browser läuft (Handy, Tablet, Rechner).
Man wählt ein Volk (Ägypter oder Waldwichtel), baut ein Dorf, sammelt Erfahrung und schaltet mit 15 Leveln neue Bauwerke und Berufe frei.

- 37 Bauwerke je Volk, 25 Berufe, Aufgaben, zufällige Ereignisse, Land das mit den Leveln wächst
- 3 Speicherplätze plus Autospeicherung (im Browser), Spielstand-Code zum Mitnehmen auf andere Geräte
- Eine einzige Datei (`index.html`), keine Installation, kein Build

## Starten

Die Datei `index.html` im Browser öffnen. Für die Schriftarten wird einmalig Google Fonts geladen. Ohne Internet nutzt das Spiel Ersatzschriften.

## Veröffentlichen mit GitHub Pages

Repository, Settings, Pages, Branch `main`, Ordner `/ (root)`.
